# FOUNDRY: builds, proves and publishes Fetch.ai agents

![tag:innovationlab](https://img.shields.io/badge/innovationlab-3D8BD3)
![tag:hackathon](https://img.shields.io/badge/hackathon-5F43F1)

Tell FOUNDRY what agent or multi-agent system you need. It quotes the cost, builds it, proves it works with
independent tests written by a different AI model that never sees the code, and publishes it to Agentverse,
then calls the live agent to confirm. FOUNDRY also improves its own engineering process: every failure becomes a
versioned skill patch that is kept only if it beats a sealed test set with zero regressions.

## Try
- "Build an agent that checks ISBN-13 numbers and replies VALID or INVALID"
- "Build two agents: a parser and a coordinator that classifies semver upgrades and asks for approval with a review card"
- "history" shows how FOUNDRY has evolved, including rejected changes
- "status" shows your jobs

## Capabilities
agent builder, code generation, verification, testing, multi-agent systems, Agentverse publishing, interactive
cards, payments, self-improving, evidence, software engineering, uAgents, ASI:One
